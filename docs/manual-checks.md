# 第一周人工检查清单

## 检查范围

当前只检查菜单、商品浏览和输入处理。注册登录、购物车和订单尚未实现，不属于本次检查范围。

| 编号 | 操作 | 预期表现 |
| --- | --- | --- |
| W1-01 | 编译后运行App | 显示第一周原型标题与主菜单 |
| W1-02 | 主菜单输入1 | 显示四个示例商品 |
| W1-03 | 在商品列表输入1 | 显示耳机的价格、库存、分类和描述 |
| W1-04 | 商品列表输入999 | 提示商品不存在，并允许继续输入 |
| W1-05 | 商品列表输入abc | 提示编号无效，程序继续运行 |
| W1-06 | 商品列表输入0 | 返回主菜单 |
| W1-07 | 主菜单输入2 | 显示项目简介和后续开发范围 |
| W1-08 | 主菜单输入无效选项 | 提示输入0、1或2 |
| W1-09 | 主菜单输入0 | 正常退出 |
| W1-10 | 标准输入结束 | 程序正常结束，不反复打印错误 |

检查时同时注意中文是否正常显示，菜单返回后是否可以继续操作。
