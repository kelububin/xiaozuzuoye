# 需求与技术规划

## 项目目标

制作一个能够在本地运行的电商控制台系统，练习Java对象、方法、集合、异常处理以及数据库操作。当前先保证程序入口和简单商品浏览能够运行。

## 最终计划功能

1. 用户注册、登录和账户信息查看。
2. 商品列表和商品详情查看。
3. 购物车添加、修改、移除与清空。
4. 创建订单、查询订单及模拟支付、发货和收货。
5. 取消订单、退款与库存恢复。
6. 会员积分、会员升级和促销优惠。

以上为完整项目的计划范围，并非第一周已经实现的功能。项目采用文字菜单；支付与物流仅演示业务流程。

## 技术方案

- Java：控制台交互、对象模型和业务逻辑。
- JDBC：后续连接MySQL，执行参数化SQL。
- MySQL：后续保存用户、商品、购物车、订单等数据。
- 目录规划：console负责菜单，model保存实体，后续增加service、db和util。
