# 第一周工作说明

## 本周目标

我们先整理电商购物的基本步骤，明确小组分工，再建立一个能运行的Java控制台入口。作为初学者，本周不急于一次完成所有业务，先熟悉类、对象和菜单循环。

## 已完成的基础内容

- 确定Java、JDBC与MySQL的整体技术方向。
- 确定项目采用控制台文字菜单。
- 建立App程序入口、ConsoleUI菜单类和Product商品类。
- 准备少量内存示例商品，支持列表浏览和按编号查看详情。
- 为错误菜单选项、错误编号和输入结束添加基础处理。
- 整理需求、开发计划和人工检查清单。

## 小组安排

宋思远负责需求和任务安排；黄一飞负责整理功能检查与问题反馈。李世君、何雨轩、李琬瑶负责后端开发，后续分别围绕账户、商品购物车、订单会员等方向开展工作。

## 学习体会

一开始我们只知道电商项目需要商品和订单，讨论以后发现还需要区分购物车与订单，以及不同状态之间的先后关系。本周通过简单菜单把操作入口固定下来，后续可以逐个接入功能。

## 下一周计划

学习数据库表之间的关系，整理用户、商品和订单等字段，尝试通过JDBC读取数据库。本周原型数据尚未保存到数据库。
